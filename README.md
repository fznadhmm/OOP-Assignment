# 📚 Repository OOP Assignment
Repositori ini bertujuan untuk menyimpan dan mengorganisir seluruh hasil pekerjaan tugas pada mata kuliah **Pemrograman Berorientasi Objek (PBO/OOP)**. 

Seluruh kode ditulis menggunakan bahasa **Java**, dengan fokus utama pada pemahaman dan penerapan pilar-pilar fundamental OOP beserta struktur datanya.

## 🗂️ Daftar Proyek Pembelajaran

Setiap folder di bawah ini mewakili modul tugas yang berbeda. Anda dapat membaca file `README.md` di dalam masing-masing folder untuk melihat detail instruksi dan penjelasan kodenya.

*   🏦 **[Simulasi Sistem Bank (Array & ArrayList)](./Array%20and%20ArrayList)**
    Proyek ini berfokus pada pengelolaan data koleksi. Saya membangun sistem perbankan sederhana yang menghubungkan entitas Nasabah (*Customer*) dan Rekening (*Account*) dengan memanfaatkan kombinasi Array konvensional dan kelas `ArrayList`.

*   📐 **[Kalkulator Bangun Geometri (Inheritance & Polymorphism)](./Inheritance%20and%20Polymorphism)**
    Proyek ini secara khusus mendemonstrasikan konsep pewarisan sifat (*Inheritance*) antar kelas geometri (bangun datar dan bangun ruang), serta bagaimana metode perhitungan luas atau volume dimodifikasi melalui mekanisme *Method Overriding* (*Polymorphism*).

## 📌 Tujuan Repositori

Repositori ini berfungsi sebagai arsip akademik, rekam jejak, serta portofolio pembelajaran saya selama menempuh mata kuliah Pemrograman Berorientasi Objek.
